# nounsql-wasm

WebAssembly bindings for the [NounSQL](https://github.com/misebox/nounsql)
compiler. Published to npm as [`nounsql`](https://www.npmjs.com/package/nounsql);
not published to crates.io.

Building and the TypeScript types are described in
[DEVELOPMENT.md](https://github.com/misebox/nounsql/blob/main/DEVELOPMENT.md).

Documentation: https://misebox.github.io/nounsql
